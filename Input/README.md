# Input Files

This folder contains the LAMMPS input files, the initial atomic structure, and interatomic potential file used in this study.

Contents

- in.equilibrate (Input file for equilibrating the system at desired temperature and pressure)
- in.shear (Input file for shear deformation)
- borophene.data (Initial atomic structure used in equilibration)
- Interatomic potential file (borophene.sw)
